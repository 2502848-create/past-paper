QUESTION 1(b) · 4 MARKS

CSS Box Model

The CSS Box Model explains how the browser displays and sizes every HTML element. It consists of four layers:

  1. Content: The actual text, image or material inside an element.
  2. Padding: Space between the content and the border.
  3. Border: The line surrounding the content and padding.
  4. Margin: The space outside the border separating elements.

QUESTION 1(d) · 2 MARKS

Ways of Applying CSS

  • Inline CSS: Written directly inside an HTML element using the style attribute. It affects one element.
  • Internal CSS: Written inside a style element in the HTML head. It styles a single webpage.
  • External CSS: Written in a separate CSS file and connected to HTML. It can style multiple webpages.

Recommendation: External CSS is best for a large multi-page government portal because it maintains consistency and makes updating the website easier.

QUESTION 1(e) · 3 MARKS

Correcting Errors in a Student Registration Form

Three problems that can occur in a student registration form:

  1. Different radio button names: Both gender options should have the same name so that only one option can be selected.
  2. Missing labels: Each input should have a label explaining what information the user should enter.
  3. Missing identifiers: Each input should have a unique ID connected to its label.

QUESTION 2(b) · 3 MARKS

Three Types of HTML Lists

  • Unordered list (UL): Displays items using bullets. Example: a bank listing services such as savings accounts and loans.
  • Ordered list (OL): Displays items in a numbered sequence. Example: steps for opening a bank account.
  • Description list (DL): Displays terms and their explanations. Example: a glossary of banking terms.
QUESTION 2(c) · 3 MARKS

Absolute and Relative Hyperlinks

  • Absolute hyperlink: Contains the full web address, including the protocol and domain. Example: linking to the Central Bank of Kenya website.
  • Relative hyperlink: Contains the path to another file within the same website. Example: linking to accounts.html.

Relative hyperlinks are useful in a bank intranet because they continue working when a website is moved to another domain, provided its folder structure remains the same.

QUESTION 2(d) · 4 MARKS

Importance of the Image Alt Attribute

The alt attribute provides a text alternative describing an image. Missing alternative text can cause several problems:

  1. Screen-reader users: Visually impaired users may not understand important health images and diagrams.
  2. Slow internet connections: If an image fails to load, alternative text can still communicate its purpose.
  3. People with learning difficulties: Text descriptions can make visual information easier to understand.
  4. Website accessibility: Missing descriptions reduce accessibility and make public-health information less available.

Example: An image showing a nurse administering a vaccine should have a meaningful description.

QUESTION 3(a) · 6 MARKS

CSS Selector Types

CSS selectors identify HTML elements that should receive particular styles.

1. Universal Selector (*)

Selects all elements on a webpage.

2. Class Selector (.classname)

Selects elements belonging to a particular class.

3. ID Selector (#idname)

Selects an element with a specific unique ID.

4. Descendant Selector

Selects elements located inside another element.

5. Pseudo-class Selector (:hover)

Applies styling when an element is in a particular state.

6. Attribute Selector

Selects elements based on their attributes or values.
