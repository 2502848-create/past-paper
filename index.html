QUESTION 1(b) · 4 MARKS

CSS Box Model

The CSS Box Model explains how the browser displays and sizes every HTML element. It has four layers:

  1. Content: The actual text, image or other material inside the element. Its width and height can be set using CSS.
  2. Padding: The space between the content and the border. It creates breathing room inside the element.
  3. Border: The line surrounding the content and padding. It can have a width, style and colour.
  4. Margin: The transparent space outside the border. It separates the element from neighbouring elements.

Application to an e-commerce product card: Content displays the product details; padding keeps those details away from the card edge; border outlines the card; and margin separates the card from other product cards.

  width: 250px;
  padding: 16px;
  border: 2px solid #6b4b35;
  margin: 12px;
}

QUESTION 1(d) · 2 MARKS

Ways of applying CSS

  • Inline CSS: Written inside an HTML element using the style attribute, e.g. <p style="color: red">. It affects that element only.
  • Internal CSS: Written inside a <style> element in the page's <head>. It styles that single page.
  • External CSS: Written in a separate .css file and connected using <link rel="stylesheet" href="css/style.css">.

Recommendation: External CSS is best for a large multi-page government portal because one stylesheet can keep all pages consistent, can be reused, and is easier to maintain and update.

QUESTION 1(e) · 3 MARKS

Correcting errors in the student registration form

Three issues to correct in the supplied snippet:

  1. Radio buttons have different names. The Male option uses name="gender" but Female uses name="sex". Give both the same name so only one option can be selected in the group.
  2. Inputs have no labels. Add matching <label for="..."> elements so users, including people using screen readers, know what each field means.
  3. Inputs have no clear identifiers. Add unique id values and connect labels to them. This also makes the form easier to use.
<form action="#" method="post">
  <label for="studentName">Student name</label>
  <input type="text" id="studentName" name="studentName">

  <fieldset>
    <legend>Gender</legend>
    <label><input type="radio" name="gender" value="Male"> Male</label>
    <label><input type="radio" name="gender" value="Female"> Female</label>
  </fieldset>

  <button type="submit">Register</button>
</form>

Exam note: The key functional error in the supplied code is the inconsistent radio-button name. The label and identifier improvements make the form accessible and easier to use.

QUESTION 2(b) · 3 MARKS

Three types of HTML lists

  • Unordered list (<ul>): Displays items with bullets. Example: a bank website listing services such as savings accounts, loans and mobile banking.
  • Ordered list (<ol>): Displays items in sequence, usually numbered. Example: steps for opening a bank account.
  • Description list (<dl>): Displays terms and their explanations using <dt> and <dd>. Example: a glossary explaining banking terms such as interest, deposit and withdrawal.
QUESTION 2(c) · 3 MARKS

Absolute and relative hyperlinks

  • Absolute hyperlink: Contains the full web address, including protocol and domain. Use it to link to an external website. Example: <a href="https://www.centralbank.go.ke/">Central Bank of Kenya</a>.
  • Relative hyperlink: Gives a path to another file within the same website. Use it for internal navigation. Example: <a href="accounts.html">Accounts</a> or <a href="staff/profile.html">Staff profile</a>.

Relative links are useful inside the bank intranet because they continue to work if the whole website is moved to another domain or server, provided the folder structure stays the same.

QUESTION 2(d) · 4 MARKS

Importance of the image alt attribute

The alt attribute provides a text alternative describing an image. If 80% of images on a public health website have no alt text, users may experience these consequences:

  1. Screen-reader users: People who are blind or have low vision may not understand important health images, diagrams or notices because assistive technology has no useful description to read.
  2. Users with slow or unreliable internet: If an image fails to load, meaningful alt text can still communicate its purpose or information.
  3. People with cognitive or learning difficulties: Text alternatives can make the meaning of visual information easier to understand when used with clear page content.
  4. Website owners and the public: Missing alternatives reduce accessibility and may make important public-health information less available to everyone.

Example: <img src="vaccination-clinic.jpg" alt="Nurse administering a vaccine to a child at a clinic">

QUESTION 3(a) · 6 MARKS

CSS selector types

Selectors identify which HTML elements should receive a CSS style.

1. Universal selector (*)

Selects every element on the page.

* { box-sizing: border-box; }
2. Class selector (.classname)

Selects all elements with a particular class.

.notice { background: #fff3cd; }
3. ID selector (#idname)

Selects the element with the matching unique ID.

#main-header { background: navy; }
4. Descendant selector (parent child)

Selects matching elements located anywhere inside another element.

.news-card p { color: #444; }
5. Pseudo-class selector (:hover)

Styles an element when it is in a particular state, such as when the pointer is over a link.

a:hover { color: orange; }
6. Attribute selector ([type="text"])

Selects elements based on an attribute or attribute value.

input[type="text"] { border: 1px solid #777; }

QUESTION 3(c) · 5 MARKS · PRACTICAL

Responsive climate-awareness campaign layout

The example uses CSS Grid for two columns: a “Quick Facts” sidebar on the left and the main article on the right. At screen widths below 600px, it becomes one column. The font uses Google Fonts with safe fallback fonts.

Quick Facts

  • Plant trees and protect forests.
  • Save electricity and water.
  • Walk, cycle or use public transport where possible.
  • Reduce, reuse and recycle waste.

CLIMATE ACTION · KENYA

Small actions. A healthier planet.

Climate change affects rainfall, food production, water availability and livelihoods. Communities can help by conserving resources, planting indigenous trees, reducing waste and choosing cleaner transport.

Schools, families and local organisations can organise clean-ups, tree-growing activities and awareness campaigns. Every practical action contributes to a more sustainable environment.

    <h1>Protect Our Climate</h1>

      and livelihoods. Everyone can take action.</p>
  </main>
</div>

Why it is responsive: The grid starts with two columns on wider screens. The media query changes the grid to one column at 600px and below, so the sidebar moves above the article on a phone.
